## API surface

1touch.io publishes **no public API**. There is no developer portal, no API reference,
no OpenAPI/AsyncAPI/GraphQL document, no SDK on any public package registry, no public
MCP server and no A2A agent card. Product documentation lives at https://help.1touch.io/docs/
behind a MadCap Central secure login, and the API host `api.1touch.io` resolves but does
not accept connections from the public internet. The platform's programmatic surface
(REST APIs, webhooks, SDKs and 100+ third-party integrations) is described only in
marketing glossary entries; the contracts themselves are customer-only.
